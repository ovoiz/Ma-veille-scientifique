Les sources sont désormais listées dans le fichier sources.json du dépôt, et non plus dans le navigateur : c'est GitHub qui relève les flux trois fois par jour, il lui faut donc la liste côté serveur. Pour ajouter ou retirer une source, édite sources.json sur GitHub ; un relevé se relance automatiquement après l'enregistrement.
